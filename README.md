## Hi there 👋

Welcome to my GitHub repository, where I develop 2D and 3D games using Unity and C#. As a game developer, I’m passionate about creating engaging, interactive experiences with strong core mechanics, responsive controls, and immersive environments. This project showcases my approach to building games with clean architecture, efficient code, and performance-conscious design.

At the foundation of every project is carefully structured game logic, written in C# and organized around Unity’s component-based system. I follow best practices in scripting, separating gameplay systems (like AI, input handling, and UI management) from engine-specific functionality. This modularity makes each game easier to maintain, extend, and debug.

A key element of the development process is working with Unity’s physics engine—both 2D and 3D. I implement realistic physics interactions, collision detection, and dynamic object behaviors to create believable game worlds. Whether it’s tuning Rigidbody properties, designing custom physics-based movement systems, or integrating user-driven interactions, physics plays a central role in how players experience the game.

I also pay close attention to performance optimization, especially important in larger or mobile-targeted projects. This includes techniques like object pooling, framerate capping, occlusion culling, and reducing draw calls. I actively profile games to find bottlenecks and refine scripts, shaders, and assets to keep gameplay smooth and responsive across platforms.

Whether you're a developer interested in Unity-based game architecture, learning how to handle real-time physics interactions, or exploring performance-first design principles, this repository offers practical examples and patterns from real-world development. Contributions and feedback are welcome—feel free to explore the code, run the demos, or reach out!
